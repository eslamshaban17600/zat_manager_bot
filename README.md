## 🎯 عن المشروع

مشروع **ذآتـ 𓂆** هو نظام خلفي وبوت تيليجرام تفاعلي مصمم لإدارة القنوات والمجموعات الإسلامية بكفاءة عالية دون الحاجة إلى لوحة تحكم خارج منصة تيليجرام. يتميز بوجود محرك جدولة قوي مع تخزين دائم في قاعدة البيانات لضمان عدم ضياع المهام عند إعادة تشغيل التطبيق، بالإضافة إلى دعم معالجة المستندات (PDF/Word) وتوليد الاختبارات، ومكتبة شاملة للمحتوى الإسلامي والختمات السماعية.

---

## ✨ المميزات الرئيسية

* **📢 إدارة القنوات:** إضافة والتحقق من صلاحية البوت (`can_post_messages`) وتخصيص النشر لكل قناة.
* **✍️ النشر الفوري:** محرر تفاعلي يدعم تنسيقات `HTML` ومعاينة المنشورات وتأكيد النشر قبل الإرسال.
* **🗓️ محرك الجدولة المتقدم:** جدولة يومية وأسبوعية وفورية تعتمد على `APScheduler` وتخزن المهام في قاعدة البيانات لضمان استمراريتها.
* **📚 مكتبة المحتوى الإسلامي:** أذكار الصباح والمساء، فوائد قرآنية، أحاديث نبوية، وتذكيرات قيام الليل.
* **📖 الختمات السماعية:** نظام لتنظيم ومتابعة تلاوات القراء وخُطط الختمات للقرآن الكريم.
* **📝 تحليل الملفات والاختبارات:** استخراج النصوص من ملفات `PDF` و `DOCX` وتحويلها إلى أسئلة واختبارات تفاعلية.
* **🛡️ سجل التدقيق (Audit Log):** تتبع جميع العمليات الإدارية الحساسة لحماية النظام وضمان أمانه.
* **💾 النسخ الاحتياطي:** دعم إنشاء نسَخ احتياطية لقواعد البيانات واستعادتها بضغطة زر.

## 📁 الهيكل البرمجي للمشروع

```text
zat_bot/
├── app/
│   ├── bot/
│   │   ├── handlers/             # معالجات الأوامر والأزرار (start, channels, publishing, scheduler...)
│   │   ├── keyboards/            # لوحات الأزرار التفاعلية (Inline Keyboards)
│   │   ├── middlewares/          # الميدل وير للحماية والصلاحيات (AuthMiddleware)
│   │   └── states/               # حالات FSM لإدارة المحادثات متعددة الخطوات
│   ├── core/
│   │   ├── config.py             # قراءة وإدارة متغيرات البيئة
│   │   └── logging_config.py     # تهيئة وتنسيق السجلات (Logging)
│   ├── database/
│   │   ├── models.py             # نماذج SQLAlchemy (ORM Models)
│   │   └── session.py            # تهيئة الاتصال بقاعدة البيانات والجلسات
│   └── services/
│       ├── channels.py           # خدمات إدارات القنوات والصلاحيات
│       ├── publishing.py         # خدمات النشر الفوري والمباشر
│       ├── scheduler.py          # محرك الجدولة واستمرارية المهام
│       ├── content_library.py    # مكتبة المحتوى الإسلامي والأذكار
│       ├── quran_audio.py        # نظام الختمات السماعية والقراء
│       ├── document_parser.py    # معالجة واستخراج النصوص من PDF/DOCX
│       └── audit.py              # تسجيل الأنشطة والأحداث الإدارية
├── data/                         # مجلد تخزين قواعد البيانات والملفات المؤقتة
├── logs/                         # مجلد سجلات النظام التشغيلية
├── .env.example                  # نموذج لإعدادات البيئة
├── main.py                       # نقطة التشغيل الرئيسية للنظام
└── requirements.txt              # الحزم والمكتبات المطلوبة
```

## 💻 المتطلبات الأساسية

* **Python:** 3.10 أو أحدث
* **Telegram Bot Token:** صادر من [@BotFather](https://t.me/BotFather)
* **Telegram Owner ID:** معرف تيليجرام الخاص بمالك البوت

## 🚀 خطوات التثبيت والتشغيل

### 1. استنساخ المشروع ودخول المجلد
```bash
git clone https://github.com/your-username/zat_bot.git
cd zat_bot
```

### 2. إنشاء بيئة افتراضية وتفعيلها
```bash
# على Linux/macOS:
python3 -m venv venv
source venv/bin/activate

# على Windows:
python -m venv venv
venv\Scripts\activate
```

### 3. تثبيت الحزم والمكتبات المطلوبة
```bash
pip install -r requirements.txt
```

### 4. إعداد متغيرات البيئة
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```bash
cp .env.example .env
```

### 5. تشغيل البوت
```bash
python main.py
```

## ⚙️ متغيرات البيئة (.env)

قم بتعبيئة الملف بالقيم الخاصة بك:

```env
# توكن البوت الصادر من BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyZ

# معرف حساب تيليجرام الخاص بالمالك (صلاحيات كاملة)
OWNER_ID=123456789

# رابط قاعدة البيانات (تلقائياً SQLite محلي)
DB_URL=sqlite+aiosqlite:///./data/zat_bot.db

# المنطقة الزمنية للجدولة
TIMEZONE=Africa/Cairo
```

## 🛠️ معمارية النظام والتقنيات المستخدمة

* **[aiogram 3.x](https://docs.aiogram.dev/):** إطار عمل حديث وسريع للتعامل مع Telegram Bot API بشكل Asynchronous.
* **[SQLAlchemy 2.x](https://www.sqlalchemy.org/) & AsyncIO:** إدارة قاعدة البيانات والعمليات غير المتزامنة.
* **[APScheduler](https://apscheduler.readthedocs.io/):** محرك جدولة المهام المتكررة والمؤجلة مع إمكانية الربط بـ SQLite JobStore.
* **[PyPDF](https://pypdf.readthedocs.io/) & [python-docx](https://python-docx.readthedocs.io/):** معالجة المستندات والنصوص.

## 🛡️ الأمان وصلاحيات الوصول

يحتوي النظام على **AuthMiddleware** يقوم بتمحيص كافة الرسائل والضغطات على الأزرار قبل معالجتها:
* يضمن عدم استجابة البوت إلا لـ `OWNER_ID` المحدد في الإعدادات أو المشرفين المصرح لهم.
* يحمي العمليات الحساسة مثل حذف القنوات، تعديل الجداول، وإنشاء النسخ الاحتياطية.
